# misc_prints

Standalone printables with **no generator script in this repo** — they were modelled elsewhere or
their source has been lost. Kept because the meshes themselves are still useful.

| File | Notes |
| --- | --- |
| `metatron.stl` | Metatron's Cube solid, 34 MB. |
| `Mandala flower of life.stl` | Flower-of-Life mandala relief. |
| `Sensor Plate 2.stl` | Sensor plate. Distinct mesh from the file below despite the near-identical name. |
| `Sensort Plate 2.stl` | Second sensor plate revision (name contains an original typo, kept to avoid guessing which is canonical). |
| `perforated_tube.stl` | Perforated tube; not referenced by any script here. |
| `tori.3mf` | Multi-object torus plate, sliced project. |
| `sacred geometry stackable.3mf` | Stackable sacred-geometry plate set, sliced project. |

If you identify the generator for any of these, move the pair into its own project directory.
